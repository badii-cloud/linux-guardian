Exposure — what this machine is listening on

Listening sockets

There is no correct number of open ports to alarm on — it depends entirely on the machine. What is always interesting is that the number changed, and only a baseline can see that.

Login sessions

Sessions, not distinct users: one person with three terminals is three. Counting usernames would hide a second login by the same account, which for a security signal is the wrong way to be wrong.
Security-relevant incident types

Declared in linux/incidents.json. A type marked security-relevant is raised one severity step higher and weighted in the risk score, so a security signal cannot be scored away as background noise.

Refusals are evidence

Every action Guardian refuses — a service outside the allow-list, a filename that climbs out of the sandbox, an approval naming an action the incident never recommended — is written to the audit trail and to the incident’s own timeline. A refusal is not an error to discard; somebody attempting something that is not permitted is exactly the event worth finding later. See the audit log.
